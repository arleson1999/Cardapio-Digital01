# prompts.md

## Prompt 1

Criar backend REST em Spring Boot para cardápio digital com produtos, categorias e pedidos. Utilizar Java 21, JPA e H2. Expor Swagger UI.

## Prompt 2

Criar frontend em HTML, CSS e JavaScript puro para consumir a API de produtos, oferecer filtro por categoria, carrinho e finalização de pedido.

## Prompt 3

Gerar documentação do projeto em RTCCO, incluindo PRD, plano de implementação, decisões arquiteturais e regras de projeto.
