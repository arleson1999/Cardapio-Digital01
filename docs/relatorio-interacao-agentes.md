# Relatório de interação entre agentes

## Agentes usados

- Backend: implementou a API REST e a persistência com Spring Boot, JPA e H2.
- Frontend: implementou a interface HTML/CSS/JS que consome a API e permite carrinho e finalização.

## Comunicação

O backend expõe endpoints JSON e a documentação Swagger; o frontend consome esses endpoints.

- Frontend funcional
